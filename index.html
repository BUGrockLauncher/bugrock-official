ENGINEERED FOR BEDROCK PLAYERS

Authentic features documented in the BUGrock Launcher v1.1.5 engine — designed for seamless version switching, world security, and community mods.

DUAL-ENGINE CORE 01

Side-by-Side GDK & UWP

Install and run official Bedrock Release, Preview, Beta, and Imported versions concurrently. Features automatic decryption key resolution and secure launch shims for modern GDK (.msixvc) versions alongside classic UWP (.appx) builds.

  • Run multiple different versions without reinstalling.
  • Drag-and-drop manual import for local .msixvc / .appx.
  • Automatic AppX registration and manifest handling.
SAVE PROTECTION 02

Multi-Instance Data Isolation

Create, clone, and manage separate game profiles. Each instance operates inside its own isolated com.mojang environment, permanently eliminating world save corruption when switching between game versions.

  • Independent worlds, texture packs, and options per version.
  • Safe junction creation with automatic pre-migration backup.
  • Clone entire installations and configurations with one click.
BACKUP ENGINE v1.1.4 03

Pre-Launch World Auto-Backup

Optional background safety routine that archives your world folders into timestamped ZIP files organized by version name before launching Minecraft. Uses direct disk streaming to prevent UI freezes on massive worlds.

  • Automated timestamped ZIP archives before every launch.
  • Direct streaming engine prevents UI freezes on large worlds.
  • "Find My Worlds" one-click button opens active save folders.
MOD & ADDON HUB 04

CurseForge & MCPEDL Browser

Integrated in-app WebView2 browser tabs for CurseForge and MCPEDL featuring built-in ad-blocking. Browse, download, and automatically install mods, texture packs, behavior packs, and custom maps with one click.

  • 1-click import: .mcpack, .mcaddon, .mcworld, & .zip.
  • Airspace Off-Screen Parking saves RAM when switching tabs.
  • Built-in ad & tracker blocking for clean web browsing.
SERVERS & PERFORMANCE 05

Live Servers & FPS Unlocker

Browse popular Bedrock community servers and join directly with one click via minecraft:// protocol activation. Customize performance with built-in framerate unlocking (144 FPS, 240 FPS, or uncapped).

  • Browse featured Bedrock multiplayer servers with live pings.
  • One-click join via native Windows protocol activation.
  • Unlock framerates beyond 60 FPS without manual file editing.
SYSTEM DIAGNOSTICS 06

BUGrock_Check & Eco Mode

Includes the bundled BUGrock_Check diagnostic tool to inspect and auto-repair critical Windows gaming services (AppXSvc, ClipSvc, GamingServices). Features Low-Performance Mode to disable animations on lower-end hardware.

  • One-click repair for disabled or missing Windows services.
  • Low-Performance Mode disables animations to conserve CPU.
  • Hardware-accelerated dark WPF interface with zero bloat.
